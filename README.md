# transit-charts

A website ([transitcharts.com](https://transitcharts.com)) with charts for public transit ridership in the United States.

This project was partially inspired by [housingdata.app](https://housingdata.app/).

## Related repositories

- [transit-parser](https://github.com/kevinji/transit-parser): Scripts that download ridership data from transit agencies and generate the data for the charts.

## Data

`data/` has the monthly average weekday ridership for each system, which the charts read. It's
generated by [transit-parser](https://github.com/kevinji/transit-parser) from files downloaded from
each transit agency.

### NYC Subway

The MTA data combines the daily ridership dataset
([MTA Daily Ridership and Traffic: Beginning 2020](https://data.ny.gov/d/sayj-mze2)) with the hourly
station-level datasets
([MTA Subway Hourly Ridership: 2017-2019](https://data.ny.gov/d/t69i-h2me),
[2020-2024](https://data.ny.gov/d/wujg-7c2s)) for days before March 2020. Days before February
2017 are estimated from turnstile entry counters
([MTA Subway Turnstile Usage Data: 2014](https://data.ny.gov/d/i55r-43gk),
[2015](https://data.ny.gov/d/ug6q-shqc), [2016](https://data.ny.gov/d/ekwu-khcy),
[2017](https://data.ny.gov/d/v5y5-mwpb)). Days before February 2014 are estimated the same way
from the weekly turnstile files the MTA used to publish at
`http://web.mta.info/developers/turnstile.html`, which are now only available from the
[Internet Archive](https://web.archive.org/web/2014/http://web.mta.info/developers/turnstile.html).
The earliest archived file starts on April 17, 2010, too late in the month to average April, and
none of them have readings for May 15 to 21, 2010. Their estimates are within about 1% of the 2014
dataset for February 2014.

### Link light rail

The Sound Transit data is queried from the Power BI report behind the ridership tracker. It covers
all Sound Transit modes from 2019, and only Link light rail is charted. Link ridership before 2019
comes from Sound Transit's
[monthly service performance reports](https://www.soundtransit.org/get-to-know-us/documents-reports/service-planning-ridership)
from September 2012 to January 2019. Each report also lists the same month of the prior year, which
covers September 2011 onward. Reports call their figures preliminary, so each month uses the figure
from the latest report that lists it.
